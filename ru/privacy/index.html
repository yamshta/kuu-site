Политика конфиденциальности KUU

Последнее обновление: 2 августа 2026 г.

Коротко: Сказанное вами принадлежит вам. Приложение никогда не отправляет саму аудиозапись за пределы устройства. На устройствах iPhone и Android расшифровка речи также происходит на самом устройстве. Версия приложения для Apple Watch не производит запись звука — она получает только текст, созданный стандартными средствами ввода watchOS (голосовой ввод, рукописный ввод или клавиатура); при выборе голосового ввода распознавание речи выполняется системой Apple (подробности в Статье 3). Для систематизации (классификации с помощью ИИ) используется внешний ИИ, но на него отправляется только расшифрованный текст. Он используется исключительно для систематизации и не сохраняется. Данные хранятся на вашем устройстве, а в версии для iOS — также в вашей частной базе данных iCloud (в версии для Android данные хранятся только на устройстве). Разработчик не сохраняет ваши записи и не имеет возможности их просматривать. Вы можете в любой момент удалить все данные из приложения. Приложение осуществляет минимально необходимый обмен данными только для обработки платежей (StoreKit на iOS / RevenueCat на Android) и показа рекламы Google AdMob, и эта информация никогда не включает сказанное вами (рекламу можно отключить, оформив подписку KUU+). Для улучшения качества мы собираем статистику использования, но она также никогда не включает сказанное вами (на iOS — с явного согласия пользователя; на Android — сбор данных, не содержащих контент, включен по умолчанию; подробности в Статье 14).

Статья 1 (Общие положения)

Приложение «KUU» (далее — «Приложение») помогает整理зовывать мысли, проговаривая их вслух. Приложение доступно в версиях для iOS (iPhone и Apple Watch) и Android, и настоящая политика распространяется на обе версии. Приложение обрабатывает информацию только в минимальном объеме, необходимом для предоставления своих функций, и считает защиту конфиденциальности пользователей своим главным приоритетом.

Статья 2 (Собираемая и хранимая информация)

Приложение обрабатывает только следующую информацию:

  1. Содержимое вашей речи (аудиоданные) — Записанный звук временно сохраняется в локальном хранилище устройства только во время расшифровки и немедленно удаляется после завершения обработки. Он не отправляется на сервер. Версия приложения для Apple Watch не выполняет запись звука (см. Статью 3).
  2. Результаты расшифровки и систематизации (текст) — Сохраняются, чтобы вы могли просматривать свои записи (в версии для iOS — на устройстве и в частной базе данных iCloud; в версии для Android — только на устройстве. На сопряженных Apple Watch для отображения сохраняются только последние заголовки в каждой категории; подробности в Статье 4).
  3. Настройки приложения — Тема оформления, размер шрифта, состояние «уровня воды в голове» и другие параметры, необходимые для работы Приложения.

Приложение не собирает личную информацию, такую как имя, адрес электронной почты, номер телефона, данные о местоположении, контакты, календарь, фотографии или идентификаторы устройства.

Статья 3 (О распознавании речи и классификации с помощью ИИ)

Распознавание речи (транскрипция) на устройствах iPhone (версия для iOS) и Android полностью выполняется на вашем устройстве (о версии для Apple Watch см. в конце этой статьи).

  • Распознавание речи: Используется фреймворк Speech от Apple (на устройстве). Сама аудиозапись никогда не отправляется за пределы устройства.

Классификация с помощью ИИ (категоризация) использует внешний ИИ:

  • Отправляется только расшифрованный текст. Аудиозапись не отправляется.
  • Данные отправляются на внешний ИИ (Gemini от Google) через сервер разработчика (бэкэнд).
  • Отправленный текст используется только для классификации и не сохраняется. Он также не используется для обучения ИИ.
  • Отправке подлежит не только расшифрованный текст речи, но и текст, введенный или отредактированный вручную. Если включено автоматическое назначение тем (функция KUU+, опционально), для распределения также отправляются заголовки, тексты и названия тем сохраненных записей (все эти данные используются только для классификации и не сохраняются).
  • В версиях для iOS до 2.3.0 можно было выбрать классификацию только на устройстве в настройках («На устройстве»), но с версии 2.3.0 эта опция больше не предоставляется.

О версии для Android: Версия для Android не предлагает способа систематизации (классификации), который бы выполнялся исключительно на устройстве. При выполнении систематизации расшифрованный текст всегда отправляется на внешний ИИ (Gemini от Google через наш бэкэнд). Отправляется только текст, сама аудиозапись не отправляется, а отправленный текст используется исключительно для классификации, не сохраняется и не используется для обучения ИИ. Сама расшифровка речи (распознавание) выполняется на устройстве.

О версии для Apple Watch: Версия приложения для Apple Watch не выполняет запись звука и распознавание речи. Для ввода используется стандартный текстовый ввод watchOS (голосовой ввод, рукописный ввод или клавиатура на выбор пользователя), и Приложение получает только итоговый текст. Если вы выбираете голосовой ввод, распознавание речи выполняется как функция Apple (watchOS), и процесс обработки (включая то, происходит ли он на устройстве или данные отправляются на серверы Apple) зависит от вашего устройства, настроек и языка, и регулируется политикой конфиденциальности Apple. Приложение не имеет доступа к этим аудиоданным, не получает и не сохраняет их. Полученный текст обрабатывается так же, как и текст, надиктованный на iPhone (классификация с помощью ИИ согласно этой статье; хранение согласно Статье 4).

Статья 4 (Хранение и синхронизация)

Версия для iOS: Результаты расшифровки и систематизации сохраняются только в вашей частной базе данных iCloud (CloudKit Private Database). Это хранилище, предоставляемое Apple, доступ к которому имеете только вы. Разработчик Приложения не может просматривать или получать доступ к сохраненному содержимому. Использование iCloud регулируется политикой конфиденциальности Apple.

Версия для Android: Результаты расшифровки и систематизации сохраняются только на этом устройстве. Автоматическая облачная синхронизация не выполняется. При смене устройства вы можете экспортировать данные в файл из раздела «Голос и данные» в приложении и импортировать его на новом устройстве. Место сохранения файла выбираете вы сами (память устройства, ваше облачное хранилище и т. д.). Разработчик не имеет доступа к этому файлу.

Версия для Apple Watch: Для отображения часть результатов систематизации (последние заголовки в каждой категории) передается на сопряженные часы Apple Watch через систему связи между устройствами Apple (Watch Connectivity) и также сохраняется на Apple Watch. Текст, введенный на Apple Watch, передается на iPhone по той же схеме. Сервер разработчика в этой передаче и хранении не участвует.

Статья 5 (Цели использования)

Обрабатываемая информация используется только в следующих целях:

  1. Создание текстовой расшифровки из вашей речи и ее отображение вам.
  2. Классификация расшифровок на категории «Посмотреть сейчас / Подумать позже / Отложить / Отпустить» и их отображение вам.
  3. Хранение и отображение сказанного вами в прошлом, чтобы вы могли к этому вернуться.
  4. Сохранение настроек, необходимых для работы Приложения.

Статья 6 (Использование внешних сервисов)

Для предоставления своих функций Приложение использует следующие внешние сервисы. Сама аудиозапись не передается ни одному из этих сервисов.

  • iCloud / CloudKit (только в версии для iOS; предоставляется Apple; хранение и синхронизация только в вашей частной базе данных)
  • Распознавание речи (в версии для iOS — фреймворк Speech от Apple, в версии для Android — встроенный в устройство движок распознавания речи; оба выполняются на устройстве, аудиозапись не покидает его пределы. Версия для Apple Watch не выполняет собственное распознавание речи, а использует стандартный ввод watchOS. См. Статью 3)
  • Стандартный текстовый ввод watchOS (только в версии для Apple Watch; предоставляется Apple; пользователь выбирает голосовой, рукописный или клавиатурный ввод. Распознавание при голосовом вводе выполняется как функция Apple и регулируется политикой конфиденциальности Apple. Приложение не имеет доступа к аудиозаписи. Подробности в Статье 3)
  • Watch Connectivity (только в версии для Apple Watch; предоставляется Apple; обеспечивает прямой обмен текстом для отображения между iPhone и Apple Watch. Сервер разработчика не задействован. Подробности в Статье 4)
  • Внешний ИИ (облачный) (для классификации; отправляется только текст; используется исключительно для классификации, не сохраняется и не используется для обучения ИИ. Подробности в Статье 3)
  • Платежные сервисы (в версии для iOS — Apple StoreKit, в версии для Android — RevenueCat; для управления покупкой, продлением, отменой и статусом подписки KUU+. Сказанное вами не отправляется. О RevenueCat см. Статью 7 и политику конфиденциальности RevenueCat)
  • Play Integrity API (через Firebase App Check; только в версии для Android) (для подтверждения целостности устройства и приложения, чтобы удостовериться, что запросы к API классификации поступают от подлинного приложения. Не содержит сказанное вами и информацию, идентифицирующую пользователя)
  • Google AdMob (Google Mobile Ads SDK) (только при отсутствии подписки KUU+; для показа одного нативного рекламного блока между разделами на экране «Что вы сказали». Сказанное вами не отправляется. Подробности в Статье 13)
  • Firebase Analytics (предоставляется Google; для улучшения качества приложения. В версии для iOS используется только если пользователь явно дал согласие в Настройках; в версии для Android события об использовании, не содержащие контент, отправляются по умолчанию (в обоих случаях сказанное вами не отправляется). Версия для iOS также использует Crashlytics при явном согласии, но версия для Android не включает Crashlytics. Подробности в Статье 14)

Сервер Приложения является минималистичным и служит только для ретрансляции запросов к ИИ для классификации, не сохраняя никакого содержимого (stateless). Сервисы аутентификации, требующие личных учетных записей, не используются.

Статья 7 (Передача данных третьим лицам)

Разработчик Приложения не имеет доступа к содержимому вашей речи, результатам расшифровки или систематизации и не передает эти данные третьим лицам.

С целью показа рекламы пользователям без подписки KUU+ в Google AdMob отправляется информация, необходимая Google для показа рекламы, включая идентификаторы устройства, рекламный ID, язык и регион устройства, приблизительное местоположение и данные о взаимодействии с рекламой (подробности в Статье 13; применяется политика конфиденциальности AdMob от Google). При активной подписке KUU+ эта передача данных не происходит.

При оформлении подписки KUU+ в версии для Android информация о покупке (ID продукта, цена, дата покупки и т. д.) отправляется в RevenueCat, Inc. для обработки платежа и управления статусом подписки (активна/неактивна). Сказанное вами не отправляется. Подробную информацию об обработке данных в RevenueCat можно найти в политике конфиденциальности RevenueCat.

Информация может быть раскрыта только в случаях, когда это требуется по закону, в соответствии с установленной процедурой.

Статья 8 (Удаление данных)

Вы можете в любой момент удалить все данные через «Настройки → Голос и данные → Удалить сохраненное» в приложении. Это действие полностью удалит данные на устройстве (а в версии для iOS — и в частной базе данных iCloud). Удаленные данные восстановить невозможно.

При удалении Приложения данные на устройстве удаляются. В версии для iOS данные в iCloud можно удалить через настройки Apple (Настройки → Apple ID → iCloud → Управлять хранилищем). В версии для Android данные хранятся только на устройстве и удаляются вместе с приложением.

Версия для Apple Watch: При удалении всех данных, данные для отображения, уже переданные на Apple Watch, будут заменены пустым содержимым при следующем подключении к часам. При удалении приложения с Apple Watch сохраненные на них данные для отображения также удаляются.

Статья 9 (Меры безопасности)

  • Версия для iOS: Временные аудиофайлы во время записи шифруются с помощью функции защиты файлов iOS (FileProtectionType.complete) и недоступны, когда устройство заблокировано. Связь с iCloud шифруется Apple по протоколу SSL/TLS.
  • Версия для Android: Записанный звук не сохраняется на диск даже в виде временного файла; он обрабатывается только в оперативной памяти и немедленно удаляется после распознавания. Сохраненные результаты расшифровки и систематизации хранятся в частной области приложения Android, недоступной для других приложений, и исключены из автоматического облачного резервного копирования Android.
  • Версия для Apple Watch: Передача данных между iPhone и Apple Watch осуществляется с помощью Watch Connectivity от Apple и не проходит через сервер разработчика. На Apple Watch хранится только текст для отображения (последние заголовки в каждой категории), аудиозаписи не хранятся.
  • Вся коммуникация с внешним ИИ шифруется (HTTPS/TLS). Сервер разработчика только ретранслирует запросы для классификации и не хранит никакого содержимого (stateless).

Статья 10 (Использование несовершеннолетними)

Приложение имеет возрастной рейтинг 4+, но, учитывая его природу (систематизация мыслей), оно предназначено для пользователей, умеющих читать и писать. Несовершеннолетним следует использовать Приложение с согласия родителей или опекунов.

Статья 11 (Изменения в политике конфиденциальности)

Настоящая политика может быть пересмотрена в связи с изменениями в законодательстве, добавлением новых функций или изменениями в спецификациях фреймворков или политик платформ (Apple / Google). О существенных изменениях будет сообщено при обновлении приложения или на публичной странице этой политики.

Статья 12 (Контакты)

С вопросами относительно этой политики обращайтесь через раздел «Разработчик» на странице приложения в App Store или Google Play, либо через «Настройки → Связаться с нами» в самом приложении.

Статья 13 (О рекламе и App Tracking Transparency)

Приложение показывает один нативный рекламный блок от Google AdMob на экране «Что вы сказали» только в том случае, если у вас нет активной подписки KUU+. Реклама отображается сдержанно между разделами, чтобы соответствовать атмосфере KUU.

  • Сказанное вами никогда не используется для рекламы (реклама не учитывает ваши расшифровки, результаты классификации или темы).
  • Для показа рекламы Google AdMob может собирать идентификаторы устройства (включая IDFA), рекламный ID, приблизительное местоположение (Coarse Location), диагностические данные и данные о взаимодействии с продуктом (информация о взаимодействии с рекламой в приложении).
  • Версия для iOS: Запрос App Tracking Transparency (ATT) отображается один раз, непосредственно перед показом первой рекламы. Реклама будет показываться даже в случае отказа, но объем информации, передаваемой Google, будет ограничен (без персонализации). Вы можете в любой момент изменить разрешение ATT в «Настройках» iOS → «Конфиденциальность и безопасность» → «Отслеживание».
  • Версия для Android: ATT — это механизм, эксклюзивный для iOS, поэтому в Android его нет. Вместо него для показа рекламы используется Рекламный идентификатор (Advertising ID) от Google. Вы можете отказаться от персонализации рекламы или сбросить рекламный ID в «Настройках» вашего устройства → «Конфиденциальность» → «Реклама» (формулировки могут отличаться в зависимости от устройства и версии Android). Кроме того, версия для Android следует правилам управления согласием (UMP), отображаемым в соответствующих регионах, таких как ЕС.
  • При оформлении подписки KUU+ показ рекламы и связанная с ней передача данных полностью прекращаются.
  • Подробнее об обработке данных в Google AdMob см. в политике конфиденциальности Google AdMob.

Статья 14 (Об использовании Firebase Analytics / Crashlytics)

Описанный в этой статье механизм явного согласия (opt-in) применяется к версии для iOS. О версии для Android см. в разделе «О версии для Android» в конце этой статьи.

Версия для iOS может использовать Firebase Analytics от Google (для сбора статистики использования) и Firebase Crashlytics (для отчетов о сбоях) с целью улучшения качества приложения и оперативного выявления проблем. Эта функция по умолчанию ВЫКЛЮЧЕНА (данные не отправляются) и активируется только в том случае, если вы явно даете на это согласие в «Настройки → Данные и диагностика».

  • Отправляемая информация:
    • Анонимизированный идентификатор установки, автоматически создаваемый Firebase (на основе IDFV; не является прямым персональным идентификатором).
    • Агрегированные сигналы о событиях в приложении (например, завершение сеанса записи, просмотр экрана оплаты и конверсия, завершение онбординга; числовые значения отправляются в сгруппированном виде с низкой детализацией).
    • Трассировка стека (symbolicated stack trace) при аварийном завершении работы приложения.
  • Неотправляемая информация: Содержимое вашей речи (аудио), текст расшифровки, текст результатов классификации ИИ и названия тем, которые вы устанавливаете, не могут быть отправлены на уровне типов в коде (реализация API не позволяет передавать строковые значения в SDK аналитики).
  • Пока согласие не дано, никакая передача данных в Firebase, включая вышеупомянутую информацию, не происходит.
  • Как прекратить отправку: Вы можете в любой момент выключить переключатель в «Настройки → Данные и диагностика». При выключении предыдущий идентификатор установки будет удален, как и все несохраненные отчеты о сбоях, хранящиеся на устройстве.
  • Получателем данных является Google LLC (США). Применяется Политика конфиденциальности Firebase от Google.

О версии для Android: Версия для Android использует Firebase Analytics для отправки событий использования, не содержащих контент (сгруппированные значения, такие как переходы между экранами и количество использований функций), и анонимного идентификатора экземпляра приложения (App Instance ID), создаваемого Firebase, в целях улучшения продукта. В отличие от версии для iOS, эта функция включена по умолчанию. Содержимое вашей речи (аудио), текст расшифровки, результаты систематизации и названия тем не могут быть отправлены благодаря дизайну, который не позволяет передавать строковые значения в SDK аналитики. Версия для Android не включает Crashlytics и не отправляет отчеты о сбоях. Получателем данных является Google LLC (США); применяется Политика конфиденциальности Firebase от Google.
